# F01_B2470_NE_N01 - 持分詳細計算処理

## 処理概要
持分法適用会社の持分詳細を計算し、持分変動を記録する処理

## ステータス
- **確定状況**: Confirmed（確定）
- **配置場所**: `20_Permanent/Designs/Processes/`

## 基本情報
- **処理ID**: F01_B2470_NE_N01
- **処理名**: 持分詳細計算処理
- **所属ジョブ**: [[domains/A&F_acc/30_Projects/Jobs/9015]]
- **実行タイミング**: 月次バッチ（月末日 23:00）

## 処理仕様

### 入力
| 項目 | データ型 | 必須 | 説明 |
|------|----------|------|------|
| target_date | DATE | ○ | 計算対象日（月末日） |
| company_code | VARCHAR(10) | ○ | 対象会社コード |
| calc_type | VARCHAR(5) | ○ | 計算タイプ（MONTH/YEAR） |

### 処理ロジック
1. 持分法適用会社一覧を取得
2. 前月末持分残高を取得
3. 当月持分変動（投資・回収・評価差額）を計算
4. 累計差分ロジックにより持分詳細を更新
5. 持分変動履歴を記録

### 出力
| 項目 | データ型 | 説明 |
|------|----------|------|
| equity_detail_id | BIGINT | 持分詳細ID |
| updated_balance | DECIMAL(15,2) | 更新後残高 |
| change_amount | DECIMAL(15,2) | 変動額 |

## SQL・コード
```sql
-- 主要SQL：持分詳細計算
UPDATE tb_equity_detail 
SET 
    current_balance = prev_balance + investment - recovery + valuation_diff,
    last_updated = CURRENT_TIMESTAMP
WHERE 
    company_code = :company_code 
    AND target_date = :target_date;

-- 履歴記録
INSERT INTO tb_equity_change_log (
    equity_detail_id, change_date, change_type, amount, created_by
) VALUES (
    :equity_detail_id, :target_date, 'MONTHLY_CALC', :change_amount, 'BATCH_F01'
);
```
