# DecisionScience Domain

> **意思決定理論・ゲーム理論・ファシリテーションドメイン**  
> データ＋行動科学による意思決定フレームワークの体系化

## 🎯 ドメインの目的

このドメインは、個人・チーム・組織レベルでの意思決定品質を向上させる理論・フレームワーク・手法を体系化します。定量分析と行動科学を組み合わせ、KPIダッシュボードやロードマップを最適化するガイドラインを提供します。

### 特徴

- **科学的根拠**: 行動経済学・認知科学に基づく意思決定理論
- **実践重視**: 実際の意思決定場面での適用事例・学び
- **定量・定性融合**: データ分析と人間心理の両面からアプローチ
- **スケーラブル**: 個人→チーム→組織の各レベルで適用可能

## 🧠 学習の進め方

### 初級者向け（1-3ヶ月）
1. **基本概念の理解**
   - 認知バイアス・ヒューリスティクス
   - 期待値理論・プロスペクト理論
   - 基本的なフレームワーク（ICE, RICE）

2. **個人レベルでの適用**
   - タスク優先順位付け
   - 意思決定ログの習慣化
   - シンプルなフレームワーク活用

### 中級者向け（3-6ヶ月）
1. **チームファシリテーション**
   - 集団意思決定手法
   - コンフリクト解決
   - ステークホルダー調整

2. **高度なフレームワーク**
   - AHP（階層分析法）
   - ゲーム理論の応用
   - シナリオプランニング

### 上級者向け（6ヶ月以上）
1. **組織戦略立案**
   - OKR設計・運用
   - ポートフォリオ最適化
   - 組織設計・意思決定プロセス改善

2. **意思決定科学の応用**
   - ベイジアン推論
   - 機械学習との組み合わせ
   - 行動変容デザイン

## 🎯 主要成果指標

- **意思決定精度**: 予想と実績の乖離率
- **意思決定速度**: 課題認識から決定までの時間
- **ステークホルダー満足度**: 意思決定プロセスへの納得度
- **実行成功率**: 決定事項の実行・成果達成率

## 💡 実用化の具体例

### KPIダッシュボード最適化
```markdown
従来: 「売上が重要だから売上KPIを表示」
改善: ICEフレームワークで各KPIを評価
- Impact: ビジネスへの影響度 (1-5)
- Confidence: データ信頼性 (1-5) 
- Ease: 改善の容易さ (1-5)
→ 総合スコアでKPI表示優先順位を決定
```

### 技術選定プロセス
```markdown
従来: 「流行りの技術だから採用」
改善: AHP法で多基準評価
- 技術的適合性 (30%)
- 学習コスト (20%)
- 運用コスト (25%)
- 将来性 (25%)
→ 重み付け総合評価で客観的選定
```
